# Contributing

Thanks for your interest in Yumdoor!

## Outside contributions: not yet

Yumdoor is currently built by two maintainers. **We are not accepting pull requests from outside contributors
yet.** Please don't open PRs; they will be closed without review.

The reason is licensing, not a lack of interest: we may want to publish Yumdoor in app stores later, which can
require offering it under a license in addition to the AGPL-3.0. Before we accept any outside code, we will decide
on a Contributor License Agreement (CLA) that makes this possible, and document it here.

Bug reports and feature ideas are welcome as GitHub issues. Please never include real personal data or
credentials, and do not post security issues publicly; report them through GitHub's
"Report a vulnerability" button on the repository's Security tab instead.

## For maintainers

The workflow (issues, branches, Conventional Commits, review rules, Tandoor version bumps) is described in
[CLAUDE.md](CLAUDE.md).
